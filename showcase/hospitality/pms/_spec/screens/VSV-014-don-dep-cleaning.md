# VSV-014 — Tổng quan dọn phòng (Housekeeping Overview)

**Loại:** Trang đầy đủ

**Route:** `VillaServicesController::cleaning()` — mặc định `/villa-services/cleaning`

**Module:** Dịch vụ lưu trú — Dọn phòng

## Mô tả ngắn gọn
Màn hình placeholder cho trang "Housekeeping Overview" trong nhóm Dịch vụ lưu trú. Action chỉ set tiêu đề trang; view chỉ hiển thị thông báo "Exciting new feature available soon." — chưa có logic nghiệp vụ nào. Tính năng dọn dẹp thực tế hiện được triển khai riêng ở màn hình Tổ dọn phòng (VSV-016 — `cleaningTeams`).
