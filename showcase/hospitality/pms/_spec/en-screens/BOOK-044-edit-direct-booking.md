# BOOK-044 — Edit Stay Request

**Type:** Popup (opened from BOOK-042)
**Route:** Booking/editDirectBooking/:id (default: `/booking/edit-direct-booking/:id`)
**Module:** Reservations

## Overview
Form for editing an existing direct booking request (before it has been approved), with the same field layout as BOOK-043 (New Stay Request).

## Detailed Description
See the field table in BOOK-043 — data is pre-loaded based on the selected request.

## Functions / Actions
- **Update** button — saves changes to the direct booking request

## Navigation
- Opened from: BOOK-042 (Direct Stay Requests) — Edit button
- Navigates to: back to BOOK-042
