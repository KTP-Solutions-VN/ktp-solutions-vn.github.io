# PAGE-001 — Platform Health Check

**Type:** Full page

**Route:** `PagesController::display(...$path)` — default `/pages/*` (the route is commented out in `config/Routes.php`, line `//$routes->connect('/pages/*', ...)`). The only view in `src/Template/Pages/` is `home.ctp`.

**Module:** Utility Pages

## Overview
This is the default welcome (scaffold) page generated by CakePHP when the project is initialized. It displays environment verification information (PHP version, extensions, directory write permissions, database connection, DebugKit) and links to CakePHP documentation. The page is displayed only when `debug = true`; if debug is disabled, it returns a 404 error (`NotFoundException`).

**Important note:** the application's actual `/` route is pointed to `LoginController::index` (see `config/Routes.php`), and the `/pages/*` route is currently commented out. As a result, this screen is currently **unused/inaccessible** in the actual business flow of the Azura Manager PMS — it exists only as unremoved CakePHP default source code.

## Detailed Description
There are no input fields or business data; the entire content consists of static technical environment diagnostic information (read from `PHP_VERSION`, `extension_loaded()`, `is_writable()`, `ConnectionManager`, `Plugin::isLoaded('DebugKit')`).

## Functions / Actions
None; only external links to CakePHP documentation/forums.

## Navigation
- There is no internal navigation to/from this screen in the actual application (the route is not activated).
