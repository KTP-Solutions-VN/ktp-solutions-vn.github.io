# CS-002-P1 — Add/Edit/Delete Language Popup

**Type:** Popup (opened from CS-002)

**Route:** Bootstrap Modal (`#exampleModal`) within `languages.ctp`; submits to the same action `CommonSettingController::languages()`; duplicate name check via AJAX `checkLanguage()` — `/common-setting/check-language`; retrieves data for editing via AJAX `getLanguageById()` — `/common-setting/get-language-by-id`.

**Module:** CS = Common Lookup Settings

## Overview
A shared popup for Adding/Editing/Deleting a language and its list of applicable countries.

## Detailed Description

| # | Field Label | Field Code | Data Type / Input | Required | Notes |
|---|---|---|---|---|---|
| 1 | Language Name | `name` | Text | Yes | Validated remotely via `checkLanguage` — returns an error if the name is duplicated |
| 2 | Applicable Countries | `country_code` | Select2 multiple (Country list) | Yes | Stored as a serialized array; `language_code` is automatically generated by the system from `name` and not shown to the user |
| 3 | Action (hidden) | `action` | Hidden (`add`/`edit`/`delete`) | — | |
| 4 | ID (hidden) | `id` | Hidden | — | Present only when editing/deleting |

In **Delete** mode: all input fields are hidden, leaving only the confirmation.

## Functions / Actions
- **Save/Update/Delete:** submits `popup_form`, saving/deleting the `Language` record.
- **Cancel:** closes the modal.

## Navigation
- Opened from: CS-002 (Language list).
- After submission: redirects back to CS-002 with a flash message.
