# BOOK-057 — Confirmation Layouts

**Type:** Full page
**Route:** Booking/confirmationTemplate (default: `/booking/confirmation-template`)
**Module:** Reservations

## Overview
List of PDF templates for booking confirmations sent to villa owners, configured by language and applied to specific business units. Each language has only 1 template.

## Detailed Description

### List (Columns)
| # | Column | Notes |
|---|---|---|
| 1 | Sr No | |
| 2 | Template | Template name |
| 3 | Business Unit | Applicable BUs |
| 4 | Created By | |
| 5 | On | Creation date |
| 6 | Actions | View/Edit/Delete |

## Functions / Actions
- **Translation** button — opens BOOK-061 (Layout Translations)
- **Add New** button — opens BOOK-058
- View template details — opens BOOK-060
- Edit template — opens BOOK-059
- Delete template (`deleteComfirmationTemplate`)

## Navigation
- Opened from: Reservations module menu > Confirmation Layouts
- Navigates to: BOOK-058 (Add), BOOK-059 (Edit), BOOK-060 (View), BOOK-061 (Translate)
