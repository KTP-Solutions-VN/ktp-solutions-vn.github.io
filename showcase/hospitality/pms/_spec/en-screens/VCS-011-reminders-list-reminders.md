# VCS-011 — Staff Reminders

**Type:** Full page
**Route:** villa-common-setting/reminders (default CakePHP DashedRoute: `/villa-common-setting/reminders`)
**Module:** VCS = Property Attributes

## Overview
Master data management screen for "Reminder" content displayed to concierge staff/guests during villa operational workflows. In addition to Add/Edit/Delete via the shared popup used by other categories, this screen also supports reordering the display order (moving items up/down) via AJAX.

## Detailed Description
| # | Field Label | Field Code | Data Type / Input | Required | Notes |
|---|---|---|---|---|---|
| 1 | No (sequence number) | — | Number | No | Auto-generated by loop index |
| 2 | Name (Reminder content) | `name` | Text | No (display only) | Retrieved from the `Reminder` table, sorted by `order_number` ascending |
| 3 | Created (creation date) | `created_at` | Datetime (`d M Y H:i`) | No (display only) | |
| 4 | Action | — | Edit/Delete/Up/Down buttons | — | Opens the VCS-011-P1 popup or reorders in place |

No dedicated search/filter field (client-side DataTable `#zero_config`).

## Functions / Actions
- "Add new" button (`.add_reminder`) → opens the VCS-011-P1 popup in Add mode; new records are always assigned the highest `order_number` + 1 (added at the end of the list).
- Edit icon (`.edit_reminder`) on each row → opens the VCS-011-P1 popup in Edit mode (only the content can be edited, not the order).
- Delete icon (`.delete_reminder`) on each row → opens the VCS-011-P1 popup in Delete Confirmation mode; upon deletion, the controller automatically decrements the `order_number` of subsequent records by 1 to avoid gaps in the sequence.
- Down arrow icon (shown on every row except the last) → calls AJAX `changeReminderOrder` with `direction=down`, swapping the `order_number` with the next record and re-rendering the table via JS without a page reload.
- Up arrow icon (shown on every row except the first) → calls AJAX `changeReminderOrder` with `direction=up`, swapping the `order_number` with the previous record and re-rendering the table via JS.
- Submitting the popup form sends a `POST` to the `reminders` action with `action=add|edit|delete`; the `VillaCommonSettingController::reminders()` controller saves/deletes records in the `Reminder` table, writes an Activity Log entry, displays a Flash message, and redirects via `referer()`.

## Navigation
- Opened from: Portfolio Setup menu > "Property Attributes" > "Staff Reminders" submenu.
- Navigates to: no navigation to another page (CRUD operations and reordering performed in place via popup/AJAX).
- Child popup: VCS-011-P1 (Staff Reminder Form).
