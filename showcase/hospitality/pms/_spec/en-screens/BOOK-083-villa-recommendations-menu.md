## Overview
An intermediate menu page for the "Villa Recommendations" feature group, providing 2 entry points: managing Criteria and running a Recommendation Check. The page itself has no data table or filters of its own.

## Detailed Description
There is no form or data table — the page consists only of 2 card-style navigation buttons/links.

| # | Item | Notes |
|---|---|---|
| 1 | Criteria | Link to BOOK-080 (list of recommendation criteria) |
| 2 | Check | Link to BOOK-084 (recommendation check) |

## Functions / Actions
- **Criteria** button/link — navigates to BOOK-080
- **Check** button/link — navigates to BOOK-084

## Navigation
- Opened from: Booking module menu > Recommendations
- Navigates to: BOOK-080 (Villa Recommendation Criteria), BOOK-084 (Recommendation Check)
