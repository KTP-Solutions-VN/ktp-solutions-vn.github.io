# BU-013 — New Reporting Zone

**Type:** Full page

**Route:** `BusinessUnitController::addZoning()` — default `/business-unit/add-zoning`

**Module:** Operating Units

## Overview
A form for adding a new business zone, assigning a custom name and selecting the Business Units belonging to the zone. The zone code (`zone_name`) is auto-generated by the system and is not entered manually.

## Detailed Description

| # | Field Label | Field Code | Data Type / Input | Required | Notes |
|---|---|---|---|---|---|
| 1 | Custom Name | `custom_name` | Text | Yes | |
| 2 | Business Unit | `business_units[]` | Checkbox (multiple) | Yes | Only displays Business Units the current user has permission for |

## Functions / Actions
- **Save:** auto-generates `zone_name` (reuses a deleted zone number if the 99-zone maximum has been reached), saves the `BusinessUnitZone` record, logs the activity.
- **Cancel:** returns to BU-012 without saving.

## Navigation
- Opened from: BU-012 (Reporting Zones) — "Add new" button.
- After saving: redirects back to BU-012.
