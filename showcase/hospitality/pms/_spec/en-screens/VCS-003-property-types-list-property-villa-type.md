# VCS-003 — Accommodation Types

**Type:** Full page
**Route:** villa-common-setting/villa-types (default DashedRoute: `/villa-common-setting/villa-types`)
**Module:** VCS = Property Attributes

## Overview
Master data management screen for "Property Type" (Villa Type), where each type is associated with one Property Category (Flat/House/Resort, etc.). When a new Villa Type is added, the system automatically creates a default set of Photo Standard Areas for that type.

## Detailed Description
| # | Field Label | Field Code | Data Type / Input | Required | Notes |
|---|---|---|---|---|---|
| 1 | No (sequence number) | — | Number | No | Auto-generated by loop index |
| 2 | Name (Property Type name) | `name` | Text | No (display only) | |
| 3 | Category | `villa_categories_id` (name displayed) | Text (mapped via `villaCategory`) | No (display only) | Name retrieved from the `VillaCategory` table, ordered with priority given to Flat/House/Resort |
| 4 | Updated (date/by) | `updated_at`/`updated_by` (falls back to `created_at`/`created_by`) | Datetime (`d M y`) + username | No (display only) | Retrieved via `CreatedUser`/`UpdatedUser` contain |
| 5 | Action | — | Edit/Delete buttons | — | Opens the VCS-003-P1 popup |

The list is sorted by `name`; no dedicated search/filter field.

## Functions / Actions
- "Add new" button (`.add_villa_type`) → opens the VCS-003-P1 popup in Add mode; upon successful save, the system automatically generates 8 standard photo areas (Drone, Exterior, Pool Day/Night, Living, Dining, Kitchen, Bedrooms & Bathrooms) along with photo quantity requirements based on the number of bedrooms.
- Edit button (pencil icon, `.edit_villa_type`) on each row → opens the VCS-003-P1 popup in Edit mode (populating `name` + `villa_categories_id`).
- Delete button (trash icon, `.delete_villa_type`) on each row → opens the VCS-003-P1 popup in Delete Confirmation mode.
- Submitting the popup form sends a `POST` to the `villaTypes` action; saves/deletes records in the `VillaType` table, writes an Activity Log entry, displays a Flash message, and redirects back to the previous page.

## Navigation
- Opened from: Portfolio Setup menu > "Property Attributes" > "Accommodation Types" submenu.
- Navigates to: no navigation to another page.
- Child popup: VCS-003-P1 (Accommodation Type Form).
