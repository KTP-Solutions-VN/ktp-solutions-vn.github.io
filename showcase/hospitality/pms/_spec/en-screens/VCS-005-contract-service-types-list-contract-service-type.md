# VCS-005 — Service Bundles

**Type:** Full page
**Route:** villa-common-setting/contract-service-types (default DashedRoute: `/villa-common-setting/contract-service-types`)
**Module:** VCS = Property Attributes

## Overview
Master data management screen for "Contract Service Type" — each type is a combination of multiple Services (see VCS-004) selected via checkboxes; the type's display name is automatically concatenated from the names of the selected services (joined by a `+` sign). Note: the navigation menu entry for this screen is currently commented out/hidden in the sidebar (`management-sidebar.ctp`), but the action and view still function when the URL is accessed directly.

## Detailed Description
| # | Field Label | Field Code | Data Type / Input | Required | Notes |
|---|---|---|---|---|---|
| 1 | No (sequence number) | — | Number | No | Auto-generated by loop index |
| 2 | Name (Type name) | `name` | Text (auto-generated) | No (display only) | Concatenated from the names of the selected Services, joined by `+` |
| 3 | Created (creation date) | `created_at` | Datetime (`d M Y H:i`) | No (display only) | |
| 4 | Action | — | Edit/Delete buttons | — | Opens the VCS-005-P1 popup |

No dedicated search/filter field.

## Functions / Actions
- "Add new" button (`.add_country`) → opens the VCS-005-P1 popup in Add mode.
- Edit button (pencil icon, `.edit_contract_service`) on each row → opens the VCS-005-P1 popup in Edit mode, with the corresponding Service checkboxes (`service_ids` decoded via `unserialize`) pre-checked.
- Delete button (trash icon, `.delete_contract_service`) on each row → opens the VCS-005-P1 popup in Delete Confirmation mode.
- Submitting the popup form sends a `POST` to the `contractServiceTypes` action; the controller concatenates `name` from the list of selected Services, `serialize()`s the `service_ids` array into the `service_ids` column of the `ContractServiceType` table, writes an Activity Log entry, displays a Flash message, and redirects back to the previous page.
